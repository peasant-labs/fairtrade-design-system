### 'create the collective' form card — internal field spacing
- **[minor/spacing]** The vertical gaps inside the form are uneven: title->subhead is tight, subhead->'name' label has a larger gap, 'name' input->'acceptance mode' is a different gap again, and the 'require redaction review' checkbox sits closer to the select than the select sat to its label. The field stack does not sit on a single 8px rhythm. Normalize every label-group to the same vertical step (e.g. --sp-2 label->control, --sp-5 between field groups) so the form reads as an even stack.

### 'create the collective' submit row (primary button + 'cancel')
- **[minor/alignment]** The amber 'create the collective' primary button is very wide and the 'cancel' button is tiny beside it, creating a lopsided action row whose right edge does not align with the input fields above it (the button row is slightly narrower/offset from the 'name' input's right edge). Make the action row span the same measure as the inputs and either give the two buttons balanced widths or right-align a compact pair so the card's right edge is consistent.

### 'forms, filters & empty states' example panel — column bottom alignment / density
- **[major/alignment]** The left form card bottom (after 'create the collective' / 'cancel' buttons) sits far higher than the right column's empty-state card bottom, so the panel has an uneven bottom edge and a large empty rectangle under the left form. If the 2-column grid is kept, the columns must bottom-align or the shorter column must be padded; better, collapse to one column (see above) so there is no mismatch.

### 'forms, filters & empty states' example panel — overall 2-column layout
- **[major/too-many-columns]** The example uses a 2-column grid: the 'create the collective' form on the left and a stack of order/provider filter rail + 'the commons is quiet' empty state on the right. The two columns are unrelated specimens forced side by side, and the left form column ends well above the right column's empty-state card, leaving a tall ragged dead zone under the form. Per the 1-column preference, stack these vertically: form, then filter rail, then empty state, each full-width. This removes the height mismatch and the ragged bottom edge.

### 'forms, filters & empty states' header cluster (H2 -> subhead -> body paragraph)
- **[major/hierarchy]** Three stacked text blocks compete: the large mono H2, the gray mono subhead ('low-traffic surfaces, left-aligned...'), and the body paragraph below it are all roughly the same measure and the subhead/body are nearly the same size and color, so the eye can't tell subhead from body. Also there is a big, inconsistent gap between subhead and body (looks ~2x the H2->subhead gap). Fix: make the subhead visibly distinct (smaller or italic, one step down the type scale), and set H2->subhead and subhead->body to the same step (e.g. --sp-3 then --sp-5) so the cluster reads as one descending hierarchy.

### 'the commons is quiet' empty-state card

Align the empty state to the same left grid (or at least match its internal padding to the form card's padding) for consistent density across the panel.

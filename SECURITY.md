# security policy

## supported versions

fairtrade is pre-1.0. only the latest published release of `@peasant-labs/fairtrade` receives security fixes.

## reporting a vulnerability

please do not open a public issue for a suspected vulnerability.

use the repository's **security** tab and choose **report a vulnerability** to send the maintainers a private report. include the affected component or export, impact, reproduction steps, and any suggested fix.

if private vulnerability reporting is not available, contact a repository maintainer through their GitHub profile and ask for a private channel. do not include vulnerability details in the initial public message.

the maintainers will acknowledge the report and assess its impact. response and remediation times depend on the report and maintainer availability. this project does not offer a bug bounty.
